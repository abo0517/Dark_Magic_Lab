# 백엔드-조계진

## 구글 로그인 연동

- 프론트 담당의 승인 기록에 따라 `FE`의 구글 버튼을 Supabase OAuth 호출로 연결했다.
- Supabase 세션 복귀와 로그아웃을 처리하고, 다른 로그인 버튼은 준비 중이라고 안내한다.
- 프론트의 Supabase publishable key를 `apikey`에, 로그인 세션 토큰을 `Authorization`에 사용하도록 수정했다.
- `FE`에서 `npm test` 11개 통과, `npm run build` 성공. 실제 Google 로그인은 Supabase·Google 설정과 Netlify 환경 변수 반영 후 브라우저에서 확인해야 한다.

참고: https://supabase.com/docs/guides/auth/social-sign-in/auth-google · https://supabase.com/docs/guides/functions/auth-headers

## 사용자 정보 저장

- `back/sql/user_profiles.sql`에 로그인 계정과 연결된 프로필 테이블, 본인만 조회·삽입·수정할 수 있는 RLS를 작성했다. 기본 권한에서 `authenticated`의 불필요한 권한도 회수하도록 수정하고 Supabase 프로젝트 `hwrxhnwijaygvlaiklik`에 마이그레이션 `20261121042327_create_user_profiles`로 적용했다.
- `FE/src/profile.js`가 닉네임·생년월일·성별·서울 구/동을 저장·조회한다. 재로그인 시 생년월일에서 만 나이를 다시 계산한다.
- 입력 화면과 내 정보 수정 화면의 저장 흐름을 DB에 연결하고, 저장 중 상태와 실패 안내를 추가했다.
- `FE`의 기존 테스트 11개 통과, 프로덕션 빌드 성공. DB에서 인증 사용자 역할로 본인 프로필 삽입·조회·수정 성공, 다른 사용자 조회·수정·삽입 차단을 확인했다. 검증 트랜잭션은 롤백했고 프로필 행 수는 0건이다. 실제 Google 로그인과 브라우저 저장 흐름은 아직 확인하지 않았다.

참고: https://supabase.com/docs/guides/database/postgres/row-level-security · https://supabase.com/docs/reference/javascript/upsert

## 카카오 로그인 연동

- 프론트 담당의 기존 소셜 로그인 연동 승인 범위에서 `FE/src/App.jsx`의 카카오 버튼을 Supabase `signInWithOAuth({ provider: 'kakao' })`에 연결했다. 구글과 동일한 복귀 URL과 세션 처리 흐름을 사용한다.
- `FE`의 `npm test` 11개 통과, `npm run build` 성공. 실제 카카오 로그인은 Kakao Developers의 앱과 Supabase Auth의 Kakao 제공자 설정 후 브라우저에서 확인해야 한다.

참고: https://supabase.com/docs/guides/auth/social-sign-in/auth-kakao

## 네이버 로그인 연동 준비

- `FE/src/App.jsx`의 네이버 버튼을 Supabase 맞춤 OIDC 제공자 `custom:naver`의 OAuth 호출로 연결했다. 기존 구글·카카오 로그인은 유지한다.
- 네이버 OIDC issuer는 `https://nid.naver.com`이며 Supabase에서 `custom:naver` 제공자를 생성해야 한다. 네이버 개발자 앱의 Client ID/Secret과 Supabase가 표시하는 Callback URL 등록이 필요하다. 이메일 없이 로그인한다면 제공자에서 `email_optional`을 켠다.
- `FE`의 `npm test` 11개 통과, `npm run build` 성공. 실제 네이버 로그인은 외부 제공자 설정 후 브라우저에서 확인해야 한다.
- 첫 브라우저 시도에서 네이버가 `invalid_scope`를 반환했다. Supabase 제공자 기본 scope가 `openid `로 전달되는 것을 확인해 네이버 OAuth 호출에 `scopes: 'openid'`를 명시했다. 인증 URL에는 `scope=openid`만 전달되는 것을 확인했다.
- 브라우저 로그인 후 Supabase `auth.identities`에서 `custom:naver` 기록 1건을 확인했다.

참고: https://supabase.com/docs/guides/auth/custom-oauth-providers · https://developers.naver.com/docs/login/devguide · https://nid.naver.com/.well-known/openid-configuration
