# 복지메이트

공공 안내문을 촬영하거나 올리면 AI가 쉬운 말로 풀어 주고, 신청 기한, 필요 서류, 접수처를 체크리스트로 알려 주는 모바일 웹 서비스입니다. (흑마술 연구소, 2026 서울AI디지털배움터 청년AI해커톤)

## 1. 무엇을 구현했는가 (11/21 기준)

- 완료: 화면 12개와 테스트(샘플 데이터 기준: 맞춤 혜택, 서류 체크리스트와 진행률, 마감 알림, 가까운 접수처, 글자 크기 3단계, 마이페이지, 설치형 웹앱), 안내문을 읽는 모델 서버(사진·PDF를 올리면 제도별 19개 항목으로 정리), 구글·카카오·네이버 로그인과 내 정보 저장, 앱의 요청을 모델 서버로 전달하는 `analyze` 함수, 공공데이터 복지서비스 목록 동기화 함수(약 480건 조회 확인), Vercel 배포(https://bokji-mate.vercel.app)
- 진행 중: 안내문 촬영부터 결과 화면까지 연결 시험, 혜택에 나이·기한 조건 값 채우기(지금은 나이로 거르지 못하고 사는 구 기준으로 보여 줌)
- 구현하지 않음: 음성 안내, 신청서 초안 작성

## 2. 어떻게 해결했는가

1. 사진을 브라우저에서 줄여(긴 변 1568px) 보내면 모델 서버가 Claude에 그대로 전달해 기한, 자격, 서류, 접수처 등 19개 항목으로 정리하고, 값 규칙(날짜, 나이 범위, 서울 구 이름, 서류 중복)을 코드로 검사해 돌려줍니다.
2. 혜택 목록은 공공데이터포털 복지서비스 API(중앙부처, 지자체)를 Supabase DB에 담아 나이와 지역 조건으로 조회합니다.
3. 대상 여부는 AI가 아니라 코드가 만 나이와 거주 구로 판정하고 "대상일 수 있어요"까지만 안내합니다. 소득·재산은 판정하지 않고 접수처 확인을 안내합니다.

## 3. 왜 그렇게 해결했는가

- 고령층이 안내문을 받고도 이해, 서류 준비, 접수처 파악이 어려워 혜택을 놓칩니다. 그래서 큰 글씨, 한 화면 한 가지, 서류 체크로 단순하게 만들었습니다.
- AI는 읽어 옮기기만 하고 근거가 없는 값은 비워 둡니다. 기한을 지어내지 않아 오답으로 인한 피해를 줄입니다.
- 오픈소스 OCR을 먼저 시험했으나 CPU 환경에서 큰 이미지가 5분 넘게 걸려, 이미지를 Claude에 바로 보내는 방식으로 바꿨습니다. 샘플 11장 중 9장에서 핵심 4개 항목이 일치했습니다(AI가 만든 참고 정답 기준).
- 개인정보는 줄입니다. 사진과 분석 결과는 서버에 저장하지 않고, 분석을 위해 외부 AI(Claude)로 전송된다는 점을 알립니다. 닉네임, 생년월일, 성별, 구·동은 로그인한 계정에만 저장하고 본인만 볼 수 있습니다.

## 실행

Node v24.21.0. 프론트: `cd FE && npm install && npm run dev` (환경변수는 `FE/.env.example` 참고). 모델 서버: `model/server/README.md`. 키는 저장소에 올리지 않습니다. 계획은 `개발계획.md`, 남은 일은 `남은구현목록.md`에 있습니다.
