# 복지메이트

공공 안내문을 촬영하거나 올리면 AI가 쉬운 말로 풀어 주고, 신청 기한, 필요 서류, 접수처를 체크리스트로 알려 주는 모바일 웹 서비스입니다. (흑마술 연구소, 2026 서울AI디지털배움터 청년AI해커톤)

## 1. 무엇을 구현했는가 (11/21 13:00 기준)

- 화면과 테스트 완료(샘플 데이터 기준): 안내문 촬영·업로드, 내 정보(만 나이 계산), 나이·구 맞춤 혜택 목록, 서류 체크리스트와 진행률, 신청 완료 표시, 마감 7일 전 알림, 가까운 접수처 찾기, 글자 크기 3단계, 마이페이지, 설치형 웹앱(PWA)
- 진행 중: 안내문 분석(OCR 서버와 Claude 파싱) 연결, 공공데이터 정책 API를 Supabase에 담아 조회, 구글 로그인
- 구현하지 않음: 음성 안내, 신청서 초안 작성

## 2. 어떻게 해결했는가

1. 사진을 브라우저에서 줄여(긴 변 1568px) 보내면 Python 서버가 OCR(PaddleOCR PP-OCRv5, CPU)로 글자를 읽고, 주민번호와 휴대전화 번호 형식을 지운 뒤 Claude로 기한, 자격, 서류, 접수처 등 19개 항목으로 정리합니다.
2. 혜택 목록은 공공데이터포털 복지서비스 API(중앙부처, 지자체)를 Supabase DB에 담아 나이와 지역 조건으로 조회합니다.
3. 대상 여부는 AI가 아니라 코드가 만 나이와 거주 구로 판정하고 "대상일 수 있어요"까지만 안내합니다. 소득·재산은 판정하지 않고 접수처 확인을 안내합니다.

## 3. 왜 그렇게 해결했는가

- 고령층이 안내문을 받고도 이해, 서류 준비, 접수처 파악이 어려워 혜택을 놓칩니다. 그래서 큰 글씨, 한 화면 한 가지, 서류 체크로 단순하게 만들었습니다.
- AI는 읽어 옮기기만 하고 근거가 없는 값은 비워 둡니다. 기한을 지어내지 않아 오답으로 인한 피해를 줄입니다.
- 개인정보는 줄입니다. 생년월일은 저장하지 않고 만 나이만 쓰며, 사진과 분석 결과는 서버에 저장하지 않습니다. 분석을 위해 외부 AI로 전송된다는 점은 화면에서 알립니다.
- GPU 없이 쓸 수 있는 오픈소스 OCR을 쓰고, 샘플 11장으로 Claude Vision과 비교해 정확도를 확인했습니다.

## 실행

Node v24.21.0. `cd FE && npm install && npm run dev` (환경변수는 `FE/.env.example` 참고, 키는 저장소에 올리지 않습니다.) 계획은 `개발계획.md`, 모델 팀 할 일은 `model/해야할일.md`에 있습니다.
