- 끝낸 항목은 이 파일에서 삭제하고, 한 일은 `model/모델-이름.md`에 적는다. 목록이 비면 이 파일을 삭제한다.
- 응답 형식은 `개발계획.md`의 "analyze 출력 데이터"가 기준이다.
- 마감은 16:00이고 이후 코드 변경은 무효다. 코드 동결은 15:45.
- 정답 검수와 평가는 팀원이 하지 않는다. 결과가 나오면 Claude(클라우드 세션)가 결과를 이미지와 직접 대조해 핵심 4개(기한, 나이, 서류, 접수처)와 지어낸 값을 점검하고 틀린 곳을 알려 준다. `model/answer.json`은 AI가 만든 참고 자료다.

## 구조
- Python 서버 하나(팀 컴퓨터에서 직접 실행, Docker 사용 안 함)가 `POST /analyze`에서 이미지나 PDF를 Claude(`claude-sonnet-5-5`)에 바로 보내 `{easySummary, programs[]}`를 받아 돌려준다. OCR 모델은 쓰지 않는다(`model/server/`).
- Supabase `analyze` Edge Function은 요청을 전달만 한다.
- 서버 주소는 공개라서 Edge Function이 보내는 공유 비밀 헤더와 파일 크기 제한을 둔다. 키(`SHARED_SECRET`, `ANTHROPIC_API_KEY`)는 서버 환경변수나 `.env`로만 둔다.
- 이미지는 Claude API(외부)로 전송된다. 이미지와 응답 내용은 저장하거나 로그에 남기지 않는다.

## 안병욱: 서버 운영과 정책 추출
1. **개인정보 공지.** 이미지는 외부(Claude API)로 전송되는데, 개인정보가 포함된 파일일 때만 이 사실을 공지한다(요구).
   - 서버 쪽은 구현함: 응답에 `hasPersonalInfo`(이미지에 특정 개인을 알아볼 수 있는 정보가 보이면 true)를 넣었다. 판별을 Claude가 하므로 전송된 뒤에 알 수 있다는 한계가 있다.
   - 남은 일(프론트와 팀 결정): 업로드 때마다 "저장하지 않아요" 고지를 띄울지, 결과 화면에서 `hasPersonalInfo`가 true일 때만 띄울지 정한다. 대안은 업로드 전에 사용자가 개인정보 포함 여부를 확인하는 방식이다. `남은구현목록.md` B와 C에 적어 두었다.
   - 서버는 프롬프트로 개인 번호를 결과에 넣지 않게 하고, 응답의 주민번호와 휴대전화번호 형식을 `[삭제]`로 바꾼다(`model/server/mask.py`).
2. **서버 운영.** 서버는 팀 컴퓨터에서 `127.0.0.1`로 열고 Cloudflare 임시 터널로 공개한다(절차는 `model/server/README.md`). 시연이 끝날 때까지 서버와 터널을 켜 두고, 터널 주소가 바뀌면 백엔드에 알린다. `SHARED_SECRET`은 길고 추측하기 어려운 값으로 정해 비공개 채널로만 전달한다. 백엔드의 `analyze` Edge Function이 아직 없다(`남은구현목록.md` A-1).
3. **정책 조건 추출(`sync-policies`용).** `model/policy_extract.py`(모델 `claude-sonnet-5-5`)는 백엔드가 준 샘플 JSON을 읽어 19개 키로 뽑는다(정책 API 호출은 백엔드 몫이라 뺐다). 백엔드에서 샘플 5건을 받아 실행하고 `model/policy_extract_result.json`을 만든다. `policies` 열을 채우는 방식은 백엔드와 정한다(`남은구현목록.md` A-2).
4. **재평가.** 프롬프트를 바꾸면 `python model/eval_server.py`로 샘플 11장을 다시 평가한다(호출 11번). 최근 결과는 11장 중 9장에서 핵심 4개 일치(`남은구현목록.md` D).
5. **기획서 AI 부분.** 처리 방식, 오류 방지 원칙(지어내지 않기, `UNREADABLE`), 개인정보 처리를 쓴다.
6. **`모델-안병욱.md` 갱신, 발표자료의 모델 설명.**

## 배준서: 파싱과 검증
1. **파싱 코드는 지웠다.** 서버가 OCR 없이 Claude에 이미지를 바로 보내게 되어 `model/server/parse.py`(OCR 텍스트용 규칙 파서)를 삭제했다(git 기록에 남아 있다).
2. **검증.** 값 규칙(날짜, 나이, `periodType`, `gu`, 서류 중복) 검사는 서버의 `validate.py`가 Claude 응답에 적용한다.
3. **평가 결과 반영.** Claude가 알려 준 틀린 곳을 고친다.
4. **포스터형 확인.** `1.jpg`, `2.jpg`처럼 글자가 적은 포스터에서 틀린 값이 채워지지 않게 한다. 틀린 값보다 빈 값이 낫다.
