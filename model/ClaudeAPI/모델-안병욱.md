# 모델 - 안병욱

## 코드
- `test_vision.py`: 폴더의 안내문 이미지(jpg, jpeg, png, webp)를 하나씩 Claude Vision(`claude-opus-5-5`)에 보내 제도별 항목을 JSON으로 받는다. 결과는 `claudeVision_test.json`에 저장한다.
  - 실행: `python model/ClaudeAPI/test_vision.py model/data`
  - 키: 저장소 루트 `.env`의 `ANTHROPIC_API_KEY`. 의존: `pip install anthropic`
  - 출력: `{"easySummary", "programs":[제도 1건 19개 키]}`. 키는 `개발계획.md`의 "안내문에서 뽑을 항목" 표를 따른다.
  - 오류: 폴더 없음, 키 없음, 이미지 없음, 5MB 초과, 거절, 응답 잘림, API 오류. 파일 하나가 실패해도 다음 파일을 계속 처리한다.
- `model/data/`: 샘플 안내문 이미지 11장.
- `model/answer.json`: 샘플 11장의 정답 데이터(AI가 이미지를 읽어 만든 참고 자료).

## 진행 상황
- Node 스크립트를 Python으로 바꿨고, 11장을 모두 돌려 JSON 파싱과 키 19개 존재를 확인했다.
- 정답 데이터를 기준으로 20개 제도를 비교했다. 일치 수는 Claude Vision이 기한 18, 나이 20, 서류 19, OCR 결과(`model/ocr/ocr-fields.json`)가 기한 19, 나이 17, 서류 18이다. 기한 불일치는 "상시"를 `always`로 보는 규칙이 이전 프롬프트에 없어서 생긴 것이다.
- 샘플 11장은 OCR 방식으로 가기로 정했다. 포스터형(`1.jpg`, `2.jpg`)은 OCR 글자가 많이 깨졌다.
- 로컬 세션에 요청함(결과 대기): OCR 서버 코드(`model/server/`), 정책 조건 추출(`model/policy_extract.py`), Opus, Sonnet, Haiku 비교(`model/model_compare.py`).
- 남은 문제
  - `test_vision.py` 프롬프트에 "상시 접수는 `always`", "`gu`는 구 이름만", "서류 중복과 안내 문구 제외" 규칙을 반영하지 않았다(OCR 방식으로 가면 Plan B용).
  - 거절(`refusal`) 응답은 재현하지 못했다.
- 다음: `model/해야할일.md`의 안병욱 항목(OCR 서버 배포, 정책 추출 확인, 백엔드 연동, 기획서 AI 부분, 발표자료).
