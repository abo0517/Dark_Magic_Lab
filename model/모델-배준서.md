# 모델 - 배준서

- `server/parse.py`는 OCR 텍스트에서 명시된 항목을 Python 표준 라이브러리와 규칙으로 추출한다. API 키와 네트워크 연결 없이 실행할 수 있다.
- `parse(text)`는 `{easySummary, programs}`를 반환한다. 핵심 항목을 읽을 수 없을 때 발생하는 `UnreadableError`는 서버에서 HTTP 422와 `{"code":"UNREADABLE"}`로 변환한다.
- 기존 OCR 텍스트 12건과 정형 입력으로 로컬 실행을 확인했다. 포스터 `1.jpg`와 `2.jpg`에서 근거 없는 마감일과 서류는 비워 두고, 65세 조건은 `2.jpg`에서만 추출한다.
- OCR이 깨진 표와 여러 제도가 섞인 포스터에는 필드 누락이나 제도 분리 한계가 있다. 이미지 원본 기준 합격률은 별도 평가가 필요하다.
