# 프론트-강준

담당: 화면, 접근성(큰 글씨, 음성 안내), 업로드 UI

## 코드 구성

- 스택: react 18.3.1, react-dom 18.3.1, vite 5.4.21, @vitejs/plugin-react 4.7.0 (외부 라이브러리 없음)
- 실행 `npm run dev` / 빌드 `npm run build` / 테스트 `npm test` (node 내장 test runner)
- `src/alerts.js` 날짜·나이·알림·판정 규칙, `src/docGuides.js` 서류 발급 안내, `src/seoul.js` 구·동, `src/mock.js` 샘플 데이터와 `analyze()` 목업
- `src/journey.js` 서류 진행 Context (App과 ChecklistScreen의 순환 import 방지)
- `src/App.jsx` 화면 전환·저장소·상태, `src/screens/` 로그인·내 정보·혜택·서류 체크(`Program`)·안내문 결과·마이페이지
- `src/components/` UI(Screen·Button·Card·StatusBox·ApplyButton·AlertBanner), 강아지 애니메이션, 카메라, 가까운 제출처
- 스타일은 `tokens.css`(값)와 `compact.css`(전체 규칙) 두 파일
